# R1 Simulator · 星海图双臂抓取仿真

基于 Three.js、R1 URDF 和 MuJoCo WebAssembly 的本地静态仿真项目。R1 页面是当前项目入口，同时保留标准机械臂参考页面及其本地依赖。

## 快速开始

需要 Python 3；运行回归测试还需要 Node.js 18 或以上。页面运行库和模型均已包含，无需安装 npm 依赖或下载模型。

```bash
git clone https://github.com/wander521/r1-simulator.git
cd r1-simulator
npm start
```

也可以直接运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`。打开 [R1 页面](http://127.0.0.1:4173/r1/)；打开 [标准机械臂参考页](http://127.0.0.1:4173/Rebot_Arm_AGV/?variant=arm) 可进行对照。若端口已被其他本地服务占用，可在上述 Python 命令中替换端口。

## 目录

```text
dist/r1/             R1 页面、控制器、逆运动学、材质和物理场景
dist/r1/assets/      R1 URDF 与 STL 模型
dist/vendor/         Three.js、模型加载器和视角控制
dist/Rebot_Arm_AGV/  标准机械臂参考页、场景和 MuJoCo WASM
work/                回归测试及模型分析工具
```

本项目的可维护页面代码位于 `dist/r1/`，`dist/` 必须纳入版本管理并整体提供静态服务。当前版本覆盖下文所列功能；与参考页的完整功能等效仍在推进中，未将完整叠放、全关节物理反馈及三语言验收声明为已完成。

## 参考项目

标准机械臂效果参考自 [yang-ci/Rebot_Arm_AGV](https://yang-ci.github.io/Rebot_Arm_AGV/?variant=arm)。保留的参考页及第三方模型、运行库归各自原作者所有。

### ReBot RS 本地抓取演示

这是原项目“标准机械臂”页面的本地复刻。它直接使用原版 MuJoCo 物理场景、机械臂与夹爪网格、接触判定和抓取轨迹，因此方块会经过接近、下降、夹持、抬升和归位，而不会被脚本直接移动到夹爪上。

爆炸时间线和零件探索面板已在本地版本中隐藏；保留一键归位与叠叠乐演示。

## 本地运行

在项目目录执行：

```bash
python3 -m http.server 4173 --directory dist
```

然后打开 <http://127.0.0.1:4173/>。

页面的 MuJoCo 运行时、模型 XML 与所有网格均存放在本地，不依赖远程资源。

## 星海图 R1 演示

打开 <http://127.0.0.1:4173/r1/> 可进入独立的 R1 双臂抓取页面。页面使用提供的 R1 URDF 与本地网格，支持选择左臂或右臂；流程为双臂展开、躯干前倾下蹲、选定侧夹爪取放，最后回到双臂垂直待命。

R1 当前入口为 `dist/r1/r1-app.mjs`。`grasp-controller.mjs` 是浏览器与回归测试共用的抓取控制器，`models/r1-contact-scene.xml` 定义桌面、三种自由物体及双侧动态夹爪。原来的 `r1.js`、`r1_grasp_scene.xml` 和旧 probe 保留作历史参考，不再由页面使用。

`r1-materials.mjs` 根据用户提供的实机照片设置暖白外壳、深灰肩颈、黑色面罩、银色臂壳、黑色夹爪与腰部机构。STL 无贴图坐标，混合色外壳按三角面分区；分组只改变渲染材质，不改变几何、关节或碰撞。模型等待全部 STL 加载完成后统一上色，避免异步加载的零件漏色。照片中的包装泡沫不属于机器人外壳，未加入模型。

抓取按固定 1 ms 物理步长运行，不依赖显示帧率。URDF 负责机器人可视化与运动学；腕部目标通过柔性约束驱动动态夹爪，四个滑动手指分别有 5 N 力限制。物体不绑定到夹爪，没有隐藏承托、碰撞球膨胀或运输阶段的位置赋值。双指持续接触后才抬升，至少实际抬升 35 mm，放置须在同色框内接触桌面并稳定，松爪后还会再次检查。身体展开、下蹲及待命姿态保留；取物时按可达性选择少量腰部转向与水平夹持方向。

参考页的实现对照：

- `assets/index-BXF1-FJz.js` 的 `$h` 为接近、下降、闭合、抬升、转运、放置、释放状态机，使用 MuJoCo 时间、IK 目标和实际物体位置；`x` / carryOffset 只是目标位置补偿，不会把物体绑定到手上。
- `rs_arm.xml` 使用分块夹爪碰撞网格、关节与受力控制；`rs_grasp_scene.xml` 的方块、长方体、圆柱为自由关节物体。R1 沿用物体尺寸、质量和摩擦参数，夹爪则根据 R1 自己的 URDF 做固定尺寸指垫。
- `o4` / `G1` 只对物体实体命中后开启编辑；空白手势交给 OrbitControls。原 R1 把 LineSegments 也纳入命中，默认 1 m 线条阈值使空白手势被误判。现仅拾取实体 Mesh，并处理取消、失焦、丢失指针捕获与第二根手指。
- `Q0` 的选择高亮用 `.5 + .5 * sin(now * .006)`，现沿用其脉冲和发光强度，支持系统减少动态效果偏好。颜色框也是参考场景相同的四根细条空心框。

交互：空白左拖旋转视角，空白右拖平移，滚轮缩放；左拖物体平移，右拖或 Shift＋左拖物体进行三维旋转，WASD 按机器人朝向移动选中物体。移物保留点击偏移，检查桌边和物体重叠。选择或切换机械臂不会复位物体，复位按钮才恢复初始场景。不可达位置会在执行前提示。

接触力曲线读取 MuJoCo 椭圆摩擦锥的约束法向力，腕部误差读取动态腕部与运动学目标之间的距离。未把运动学关节角度冒充力矩。相机布局、画面开关、腕部相机模型开关、关节角度提示和末端拖动均有对应交互。

运行真实控制流程回归测试：

```bash
npm test
```

覆盖左右臂 × 三种任务物、拖动后位置、旋转后的蓝色长方体与侧躺圆柱。测试与页面共用同一控制器和物理场景，检查接触、抬升、速度及释放后的落桌状态。WASM 接触包装对象读取后立即释放，避免持续查看接触数据导致内存增长。
