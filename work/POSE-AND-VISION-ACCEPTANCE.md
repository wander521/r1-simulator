# 待命姿态、R1 原生相机与自然抓取验收

日期：2026-10-16。对象为当前 `main` 的 `/r1/`、`/c5/`、`/multi/`；这是既有工作台的普通扩展，沿用 Operate 模式、深蓝/青色界面、中文系统字体、原机器人材质和响应式布局。本文区分本轮实现、当前验证及历史证据；数值仿真不构成硬件认证。

## 当前实现

| 项目 | 实现与保持的约束 |
| --- | --- |
| C5 待命 | 六轴 HOME 为 `[0,.10,1.25,-.42079632679489665,π/2,0]rad`，上臂接近竖直、肘部前弯、Dex1 朝下；初始加载、复位、自动返回写入真实动力学目标。照片约束轮廓，不是关节帧或硬件标定。 |

| R1 原生相机 | 仅使用原 URDF 左右 `realsense_link` 与原 STL；无额外合成盒体、镜头、支架。镜头中心 `[.0325,0,.001]m`、视线 `[0,0,1]`、up `[0,-1,0]` 为源网格推断；FOV `62.82°` 是软件视野约定。显隐控制两侧原生相机，腕部画面排除其自身网格。 |

| R1 转腰 | 在源腰部关节帧计算候选，并比较完整取放可行性；同一取放路径共用腰角，接近前完成转腰。叠放换向先按旧腰角收臂清障，再仅转腰；携物阶段不转腰。 |
| 三站取景 | 1.6m 相邻中心间距保留；静止视角按当前实际轮廓拟合，准备/执行时纳入较大运动保护边界。模型、物体、桌台、本地物理坐标不缩放；参与选择与观察聚焦互相独立。 |
| 浏览器缓存 | R1/C5/multi HTML importmap 将相关模块及旧查询别名统一到 `20261016-native-camera-3`，避免本轮姿态与旧合成相机依赖混装。 |

物理模型的源关节、限位、速度、力矩、惯量与接触参数保持原值；物体仍通过重力、摩擦与实际双指接触运动，不增加焊接、吸附、隐藏承托或携物时的位置赋值。
