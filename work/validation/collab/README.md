## 证据解释

物理报告记录实际刚体标识、双指接触力、抬升、落点/支撑、载物输送及原模型对象连续性。运行前后源码哈希必须一致，并与最终源码逐项比对。连续订单报告应保留同一 Model/Data、单调物理时间，以及已出料托盘上的第一单物料未被重置的证据。

真实浏览器报告必须从正常“开始 5 分钟作业”按钮启动，使用未修改的真实墙钟，保留周期快照、参与本体、运行阶段与实际成果。等待实体补料、失败、提前退出或静置计时不能作为连续生产通过。300 秒后允许安全收尾，未完成订单不能计入成品。

`baseline-` 是旧固定交接位的历史证据，不代表当前托盘待装料流程。`development` 包括定位碰撞、输送与状态问题时的真实失败记录，保留以便追溯，不能用成功文件覆盖并隐去失败。

## 建模边界

R1 底盘为带碰撞代理的理想平面伺服，不是轮地牵引或任意自主导航；托盘为双轴伺服与理想滚轮法向支承，不是实体皮带驱动。零件仍由接触/摩擦搬运，不焊接、不吸附、不在运输时改写位置。

R1 源模型没有完整外壳碰撞，G1/C5 使用原凸包碰撞网格；本演示不构成完整全身安全验证或实机控制认证。C5 下线可以由可达的 G1 接替装盘，R1 供料和 G1 阀体链仍是整单必需能力；不是任意单机独立完成整单。
